# FootsiesRL
A Reinforcement Learning approach to Footsies game

How to install the training environment:

```
# To create a virtual environment, run:
python3 -m venv .venv
source .venv/bin/activate

# To install the dependencies, run:
pip install -r requirements.txt
```

**IMPORTANT**: both in `test.py` and `visual_test.py` you have to set the correct platform depending on your OS. Use `"mac"` if you are on MacOS, or `"linux"` if you are on Linux. **Windows not supported**.
